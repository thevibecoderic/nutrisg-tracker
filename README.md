# NutriSG Tracker
A clean, fast calorie and macronutrient tracker built for daily health logging. It works offline-first and syncs seamlessly when your network returns.

## 🚀 Features

- **Offline Support:** Logs your meals even without internet and syncs automatically when you're back online.
- **Dark Mode:** Automatically matches your phone/system settings.
- **Secure Login:** Keeps passwords completely safe using advanced server-side encryption.

## 🛠️ Built With

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js (Vercel Serverless)
- **Database:** Supabase
